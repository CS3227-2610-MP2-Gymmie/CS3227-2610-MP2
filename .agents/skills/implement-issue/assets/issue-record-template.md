# Issue Record

Use this template only when persistent evidence recording is requested. Save the completed record at the location specified by the user or established by repository convention. Keep entries concise; write `Unavailable` or `Not checked` where facts cannot be established. Record observations as agent evidence and reserve judgments for the human-review section. Issue records support practical review and remain separate from session logs.
